# Privacy policy: GSO Village (gboro)

GSO Village is a personal, non-commercial community project that shows public goings-on in Greensboro, NC as a pixel-art village.

## Google account data

The project's data collector uses Google's Gmail API with **read-only** access (`gmail.readonly`) to one project inbox. It only reads emails whose subject contains "Greensboro update", which are automated digests of public local posts and news. It does not read, store or share any other mail. It never sends, changes or deletes email.

The text of those digests is processed into a list of public events and news items with links to the original public posts. Raw digest text is kept only for the length of a single build run and is not published. Individuals' names are removed or held back before anything is shown on the site.

Google data is not sold, used for advertising, or shared with anyone. Use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements.

## Site visitors

The website does not ask visitors to sign in, does not set tracking cookies, and does not collect personal information.

## Removal requests and contact

To have an item removed or to ask a question, open an issue at https://github.com/ekalb81/gboro/issues.
